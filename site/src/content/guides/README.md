# Guides live elsewhere

The long-form local SEO guides published at https://locan.ai/guides/ are editorial content and are
not part of this open-source repository. The site builds without them — guide sections, cards and
links simply don't render when this folder holds no `.mdx` files.

To write your own guides, add `<slug>.mdx` files here that match the schema in `src/content.config.ts`
(title, description, pillar, published, …). Only `.mdx` files are loaded, so this README is ignored.
